# hxyfront-62013 木结构榫卯构件测绘

源提示词编号：8

古建筑木结构榫卯构件测绘前端项目。现场登记建筑名称、构件编号、木材种类、榫卯类型、截面尺寸、病害位置、变形情况和修缮建议。

## 功能

- **构件登记工作台**：新增、修改、移除构件记录，记录保存在本机浏览器（localStorage），下次打开自动恢复，可接着上次继续查。
- **筛选与导出**：清单按建筑名称和榫卯类型筛选，导出 CSV 与当前筛选结果一致（带 BOM，Excel 直接打开不乱码）。
- **编号查重**：同一建筑内构件编号重复时不另建新记录，提示已有资料并自动打开原记录。
- **修缮建议状态**：建议未确定可先保存并标记为“待补”；已有确定建议的记录不允许退回待补或清空，已填内容不会被后续编辑覆盖。
- **统计指标**：构件数量、病害点、榫卯类型数、待补修缮建议数。

## 技术栈

React + Vite + TypeScript
