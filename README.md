# hxyfront-62013 木结构榫卯构件测绘

开发一个古建筑木结构榫卯构件测绘前端项目，测绘人员可以录入建筑名称、构件编号、木材种类、榫卯类型、截面尺寸、病害位置、变形情况和修缮建议。

## 构件登记工作台

- **新增 / 修改 / 移除**：在左侧表单登记构件，清单中可直接编辑或移除（移除前确认）。
- **本机持久化**：记录保存在浏览器 localStorage，关闭后再打开可接着查；首次打开提供 3 条示例，可随意修改或删除。
- **按建筑 + 榫卯类型筛选**：另支持关键词搜索；指标、清单与导出均基于当前筛选结果。
- **导出 CSV**：导出内容与当前筛选结果完全一致（含建议状态、修缮进度、更新时间，带 BOM 可直接用 Excel 打开）。
- **构件编号去重**：同一建筑下构件编号重复（忽略大小写、首尾空格）时不另建新记录，提示已有资料并可一键打开原记录。
- **待补建议保护**：修缮建议未确定可先保存，自动标为「待补」；已经填写的建议在后续编辑中不会被清空或覆盖。
